## KEY BEHAVIOR TO REPLICATE (CRITICAL)

1. App-based access (X-Rutba-App)
2. Admin elevation (X-Rutba-App-Admin)
3. Owner-based access (owners relation)
4. Auto-ownership on create
5. Owner filtering on read
6. Ownership validation on update/delete
7. Elevated users bypass ownership
8. Non-owner access ONLY when elevated

THIS MUST NOT BREAK.

---

## TARGET SYSTEM (NEW PLUGIN)

The plugin will implement:

1. Domain-based access (replaces app-access keys)
2. Role-based access (staff, manager, admin)
3. Policy-based permissions
4. Condition-based access (ABAC)
5. Ownership enforcement
6. Context-based evaluation (domain + elevation)
7. Query-level filtering
8. Field-level permissions (later phase)
